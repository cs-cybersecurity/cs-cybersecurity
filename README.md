I'm a cybersecurity professional with experience spanning **malware analysis, threat intelligence, detection engineering, security operations, and infrastructure**. - 🧪 **Always learning:** Vulnerability research, penetration testing, exploit development fundamentals, and offensive security through hands-on labs.
- 🛠️ **I like building:** Practical security automation, detection content, investigative workflows, and self-hosted projects.
